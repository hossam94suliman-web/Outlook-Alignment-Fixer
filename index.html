    What this fixes:
    rebuilds display:inline-table fluid-hybrid columns (the #1 cause of Outlook
    misalignment) into real <table><td width="%"> rows, normalizes column widths to
    sum to 100%, preserves font-family/font-size/color/line-height on every converted element,
    keeps all classes used by your mobile media queries in their original ancestor order, converts
    <hr> dividers to Outlook-safe 1px table cells, patches mobile column-stacking
    rules to work with real table cells, and adds an inline mso-hide:all fallback to any
    section that's unconditionally display:none outside a media query — protecting against
    Outlook/Outlook.com configurations that strip <style> blocks and would otherwise
    make "mobile-only" sections appear duplicated on desktop.

    
    What it won't guess at:
    real CSS flex/grid layouts are flagged, not auto-converted — rebuilding those
    safely needs a human decision about column structure. Always give the output a quick visual QA pass
    before sending.
